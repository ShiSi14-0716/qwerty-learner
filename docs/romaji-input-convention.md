## 三、特殊音

| 音 | 规则 | 示例 |
|---|---|---|
| 拨音 ん | **nn** | かん→kann、しん→sinn |
| 促音 っ | 双写后辅音 | パニック→panikku |
| 长音 | 双写元音 | きゅう→kyuu、こう→kou、ねえ→nee |
| 外来长音 ー | 连字符 `-` | チャーミング→tya-minngu |
